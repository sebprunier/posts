# sebprunier/posts

My personal tech blog — experience reports, experiments, and dev notes.

🌐 **[sebprunier.github.io/posts](https://sebprunier.github.io/posts/)**

## Built with

- [Jekyll](https://jekyllrb.com/) — static site generator
- [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) — theme (skin: air)
- [jekyll-polyglot](https://polyglot.untra.io/) — FR/EN multilingual support
- [GitHub Actions](https://github.com/features/actions) — automated build & deployment

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Then open [http://localhost:4000/posts/](http://localhost:4000/posts/).
